Pulse WiFi 1.0 preview
Apple silicon (M1 and newer) | macOS 14 or later

INSTALL
Extract the ZIP and move Pulse WiFi.app to Applications. Open the app and use its Wi-Fi icon in the menu bar.

This preview is locally signed, not Developer ID signed or notarized. Only open downloads from a source you trust. If macOS blocks this preview, review System Settings > Privacy & Security > Open Anyway. See https://support.apple.com/102445. Do not disable Gatekeeper globally.

WI-FI DETAILS
Choose Enable Wi-Fi details and allow Location access to read your network name. The app does not request location updates or store coordinates. Review protected settings in System Settings when automatic verification is unavailable.

TESTS AND PRIVACY
Speed tests run only on demand and transfer substantial internet data. Optional automatic connection checks contact Apple's test endpoints and skip metered/Low Data Mode connections. Observations remain in memory; only preferences are saved. Quitting clears observations.

Configuration checks do not certify that a network is safe. Private Wi-Fi Address and Private Relay activation are manual checks. The app does not scan other devices or change firewall settings.
